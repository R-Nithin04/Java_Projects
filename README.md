# Java Programs

A collection of Java programs created while learning and practicing Core Java concepts.

## 📌 About
This repository contains beginner to intermediate Java programs covering programming fundamentals, object-oriented programming, and problem-solving.

## 🛠️ Technologies Used
- Java
- Eclipse IDE
- JDK 17+ (Compatible with most Java versions)

## 📂 Topics Covered
- Variables & Data Types
- Operators
- Conditional Statements
- Loops
- Arrays
- Methods
- Strings
- Object-Oriented Programming (OOP)
- Exception Handling
- Collections
- File Handling
- Pattern Programs
- Number Programs

## ▶️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/java_project.git
   ```
2. Open the project in Eclipse or IntelliJ IDEA.
3. Compile and run any Java file.

This repository serves as a personal learning archive and coding practice collection to strengthen Java programming skills.
